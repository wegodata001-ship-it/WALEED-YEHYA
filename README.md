# WALLED YEHYA GROUP ERP

מערכת ניהול לחקלאות וקבלנות  
נבנתה ע״י **WEGO BUSINESS**

## התקנה ראשונה

1. התקן [Node.js 20+](https://nodejs.org/)
2. פתח את התיקייה בטרמינל והרץ:

```bash
npm install
npm run db:setup
npm run dev
```

3. פתח בדפדפן: http://localhost:3000

## התחברות ראשונית

| שדה | ערך |
|-----|-----|
| טלפון | `0500000000` |
| סיסמה | `1234` |

לאחר הכניסה רשום עובדים, לקוחות, מכונות וכלי רכב במחלקות.

## מחלקות במערכת

- **לוח בקרה** — סיכום לפי מחלקה
- **מכונות** — יומן עבודה ורישום
- **תפעול** — דלק, מיכלים, אישורים
- **כספים** — כרטסות, תשלומים ותקבולים
- **כלי רכב** — רישום צי וטיפולים
- **לקוחות** — בעלי שדה והתחשבנות
- **עובדים** — רישום, שעות ונוכחות
- **ממשק שטח** (`/mobile`) — דיווח מהשטח

## הפעלה לפרודקשן

```bash
npm run build
npm run start
```

מומלץ להחליף את `JWT_SECRET` בקובץ `.env` לערך אקראי ארוך.
